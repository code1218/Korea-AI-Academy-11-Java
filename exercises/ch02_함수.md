## 1. 개념 확인

### 문제 1-1 ⭐
수업에서 함수를 "도구를 만드는 것"이라고 했습니다. 함수를 사용하는 **두 가지 이유**를 쓰세요.

<details><summary>정답 보기</summary>

1. **재사용성** – 같은 작업(업무일지 출력)을 여러 번 복사·붙여넣기 하지 않고 호출만 하면 된다.
2. **정리** – 코드에 이름(`업무일지출력`, `날짜표기변환`)이 붙어 무슨 일을 하는지 읽기 쉬워진다.
</details>

### 문제 1-2 ⭐
다음 함수 선언의 각 부분 이름을 쓰세요.

```java
String 날짜표기변환(String date) { ... return ...; }
//  ①       ②          ③                  ④
```

<details><summary>정답 보기</summary>

① 반환 타입 ② 함수(메서드) 이름 ③ 매개변수 ④ 반환값을 돌려주는 `return`
</details>

### 문제 1-3 ⭐⭐
수업 코드의 `업무일지기능`과 `업무일지기능2`는 둘 다 업무일지를 출력하지만 데이터를 받는 방식이 다릅니다. 차이를 설명하세요.

<details><summary>정답 보기</summary>

- `업무일지기능`: 데이터를 **필드**(`f1.date = ...`)에 먼저 저장해 두고, `업무일지출력()`은 매개변수 없이 필드 값을 사용한다.
- `업무일지기능2`: 데이터를 **매개변수**(`업무일지출력("2026-09-27", "김준일", ...)`)로 호출할 때마다 전달한다.
  객체 하나(`f3`)로 여러 번 다른 내용을 출력할 수 있다.
</details>

## 2. 출력 결과 예측

### 문제 2-1 ⭐
```java
업무일지기능2 f3 = new 업무일지기능2();
String result = f3.날짜표기변환("2026-01-05");
System.out.println(result);
System.out.println(result.length());
```

<details><summary>정답 보기</summary>

```
2026년 01월 05일
13
```
`split("-")`은 문자열을 `"-"` 기준으로 잘라 `["2026", "01", "05"]` 배열을 만듭니다. 문자열이므로 `01`의 앞자리 `0`도 그대로 남습니다.
`"2026년 01월 05일"`은 공백 2개를 포함해 13글자입니다.
</details>

### 문제 2-2 ⭐⭐
```java
int[] nums = f3.fx1();
System.out.println(nums[0] + nums[1]);
System.out.println("합: " + nums[0] + nums[1]);
```

<details><summary>정답 보기</summary>

```
30
합: 1020
```
- 함수는 값을 **하나만** 반환할 수 있어서, 여러 값을 돌려주고 싶으면 `fx1()`처럼 **배열로 묶어서** 반환합니다.
- 두 번째 줄은 문자열 `"합: "`과 먼저 더해지므로 `"합: 10"` → `"합: 1020"`이 됩니다.
  숫자 합을 원하면 `"합: " + (nums[0] + nums[1])`처럼 괄호가 필요합니다.
</details>

## 3. 오류 찾기

### 문제 3-1 ⭐⭐
다음 함수들 중 **컴파일 에러가 나는 것**을 모두 고르고 이유를 쓰세요.

```java
class 계산기 {
    int 더하기(int a, int b) {        // ①
        return a + b;
    }

    int 빼기(int a, int b) {          // ②
        int result = a - b;
    }

    void 인사(String name) {          // ③
        System.out.println("안녕 " + name);
    }

    String 나이표시(int age) {         // ④
        return age;
    }
}

계산기 c = new 계산기();
int v = c.인사("준일");               // ⑤
```

<details><summary>정답 보기</summary>

**②, ④, ⑤**가 에러입니다.

- ② 반환 타입이 `int`인데 `return`이 없습니다. → `missing return statement`
- ④ 반환 타입이 `String`인데 `int`를 반환합니다. → `return age + "살";` 처럼 문자열로 만들어야 합니다.
- ⑤ `void` 함수는 **아무 값도 돌려주지 않으므로** 변수에 담을 수 없습니다.
</details>

### 문제 4-1 ⭐ 시간 표기 변환
`"14:30"` → `"14시 30분"` 으로 바꾸는 `String 시간표기변환(String time)`을 완성하세요.
(힌트: 수업의 `날짜표기변환`과 같은 방법, `split(":")`)

### 문제 4-2 ⭐⭐ 전화번호 가리기
`"010-1234-5678"` → `"010-****-5678"` 으로 바꾸는 `String 전화번호마스킹(String phone)`을 완성하세요.

### 문제 4-3 ⭐⭐ 여러 값 반환
`"2026-09-29"` 를 받아 `{2026, 9, 29}` 처럼 **숫자 배열**로 돌려주는 `int[] 날짜분리(String date)`를 완성하세요.
(힌트: 문자열 `"09"`를 숫자 `9`로 바꾸려면 `Integer.parseInt("09")`)

### 문제 4-4 ⭐⭐⭐ 함수 안에서 함수 호출
날짜와 시간을 받아 `"2026년 09월 29일 14시 30분"`을 반환하는 `String 일시표기(String date, String time)`를 완성하세요.
단, 직접 `split` 하지 말고 **이미 만든 `날짜표기변환`, `시간표기변환` 함수를 호출**해서 만드세요.

<details><summary>정답 보기</summary>

```java
String 시간표기변환(String time) {
    String[] splitTime = time.split(":");
    return splitTime[0] + "시 " + splitTime[1] + "분";
}

String 전화번호마스킹(String phone) {
    String[] parts = phone.split("-");
    return parts[0] + "-****-" + parts[2];
}

int[] 날짜분리(String date) {
    String[] splitDate = date.split("-");
    int year = Integer.parseInt(splitDate[0]);
    int month = Integer.parseInt(splitDate[1]);
    int day = Integer.parseInt(splitDate[2]);
    return new int[] {year, month, day};
}

String 일시표기(String date, String time) {
    return 날짜표기변환(date) + " " + 시간표기변환(time);
}
```
</details>
