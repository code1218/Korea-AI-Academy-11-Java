## 푸는 방법

1. **개념 확인 / 출력 예측 / 오류 찾기** 문제는 먼저 코드를 실행하지 말고 **종이에 답을 써 본 뒤** 확인하세요.
2. 정답은 각 문제 아래 `정답 보기`를 클릭하면 펼쳐집니다.
3. **코드 작성** 문제는 `src/main/java/com/korai/study/practice/` 아래의 실습 파일에서 `TODO` 부분을 채워 실행하세요.
   실습 파일은 처음 상태로도 컴파일되므로 바로 실행해 볼 수 있습니다.
