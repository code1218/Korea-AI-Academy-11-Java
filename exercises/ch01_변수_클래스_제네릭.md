## 1. 개념 확인

### 문제 1-1 ⭐
다음 코드에서 컴파일 에러가 나는 줄은 몇 번째 줄이고, 그 이유는 무엇일까요?

```java
int num = 10;                    // 1
final String name = "김준일";     // 2
num = 20;                        // 3
name = "김준이";                  // 4
```

<details><summary>정답 보기</summary>

**4번째 줄**입니다. `final`이 붙은 변수는 **상수**라서 처음 값을 넣은 뒤에는 다른 값을 대입할 수 없습니다.
`num`은 일반 변수이므로 3번째 줄처럼 값을 바꿀 수 있습니다.
</details>

### 문제 1-2 ⭐
빈칸을 채우세요.

- 클래스는 객체를 만들기 위한 ( ① )이고, `new 학생()`으로 만들어진 실체를 ( ② )라고 한다.
- 클래스 안에 선언된 `String name; int age;` 같은 변수를 ( ③ )라고 한다.
- 객체의 필드에 접근할 때는 `jun.name` 처럼 ( ④ ) 연산자를 사용한다.

<details><summary>정답 보기</summary>

① 설계도(틀) ② 객체(인스턴스) ③ 필드(멤버 변수) ④ `.` (점)
</details>

## 2. 출력 결과 예측

### 문제 2-1 ⭐⭐ 값 복사 vs 참조 복사
실행 결과를 예측해 보세요.

```java
int num = 10;
int num2 = num;
num = 20;
System.out.println(num2);

class Student {
    String name;
    int age;
}

Student jun = new Student();
jun.name = "김준일";
jun.age = 33;

Student other = jun;
other.age = 40;
System.out.println(jun.age);
```

<details><summary>정답 보기</summary>

```
10
40
```

- `int` 같은 **기본 자료형**은 `num2 = num` 할 때 **값 자체가 복사**됩니다. 이후 `num`을 바꿔도 `num2`는 그대로 10입니다.
- 클래스로 만든 **참조 자료형**은 `other = jun` 할 때 **객체의 주소(참조)가 복사**됩니다.
  `other`와 `jun`은 **같은 객체**를 가리키므로 `other.age`를 바꾸면 `jun.age`도 40이 됩니다.

> 💡 ch03 `StaticLibrary`의 `도서 b3 = b1;` 도 같은 원리입니다.
</details>

## 3. 오류 찾기

### 문제 3-1 ⭐⭐ Object 타입
수업 코드의 `Student2`는 `age`를 `Object` 타입으로 선언했습니다.
아래 ①~⑤ 중 **컴파일 에러가 나는 것**을 모두 고르세요.

```java
class Student2 {
    String name;
    Object age;
}
Student2 s = new Student2();

s.age = 33;            // ①
s.age = "33";          // ②
s.age = new Student(); // ③
s.age = null;          // ④
int x = s.age;         // ⑤
```

<details><summary>정답 보기</summary>

**⑤번**만 에러입니다.

- `Object`는 모든 타입의 조상이라서 숫자, 문자열, 객체, `null` 무엇이든 **넣을 수 있습니다**(①~④).
- 하지만 꺼낼 때는 `Object` 타입이므로 그대로 `int` 변수에 담을 수 없습니다.
  → `error: incompatible types: Object cannot be converted to int`
- 이처럼 "아무거나 담을 수 있지만 꺼낼 때 타입을 알 수 없는" 불편함을 해결하는 것이 바로 **제네릭**입니다.
</details>

### 문제 3-2 ⭐⭐ 제네릭
다음 중 **컴파일 에러가 나는 줄**을 모두 고르고 이유를 설명하세요.

```java
class Student3<A> {
    String name;
    A age;
}

Student3<String> s1 = new Student3<>();
s1.age = "33";           // ①
s1.age = 33;             // ②

Student3<Integer> s2 = new Student3<>();
s2.age = 33;             // ③
int age = s2.age;        // ④

Student3<?> s3 = s2;     // ⑤
Object o = s3.age;       // ⑥
s3.age = 50;             // ⑦
```

<details><summary>정답 보기</summary>

**②, ⑦**번이 에러입니다.

- ② `Student3<String>`은 `A`가 `String`으로 정해졌으므로 숫자를 넣을 수 없습니다.
- ④ `Student3<Integer>`의 `age`는 `Integer`이므로 `int`에 바로 담을 수 있습니다(`Object`와 달리 형변환 불필요).
- ⑤ 와일드카드 `<?>`는 "어떤 타입이든 상관없는 Student3"를 받을 수 있습니다.
- ⑥ 어떤 타입인지 모르지만 최소한 `Object`이므로 `Object`로 꺼내는 것은 가능합니다.
- ⑦ 컴파일러 입장에서는 `?`가 정확히 무슨 타입인지 모르기 때문에 **값을 넣을 수 없습니다**(`null` 제외).
</details>

### 문제 4-1 ⭐ 클래스 만들기
`main` 안에 `상품` 클래스를 만들고 객체 두 개를 생성하세요.

- 필드: `String 이름`, `int 가격`, `int 재고`
- 객체1: 이름 `"키보드"`, 가격 `30000`, 재고 `5`
- 객체2: 이름 `"마우스"`, 가격 `15000`, 재고 `10`
- 두 상품의 정보를 `키보드 30000원 (재고 5개)` 형식으로 출력

### 문제 4-2 ⭐⭐ 제네릭 클래스
`상자<T>` 클래스를 만들고 서로 다른 타입의 상자를 만들어 보세요.

- 필드: `String 라벨`, `T 내용물`
- `상자<String>` : 라벨 `"편지"`, 내용물 `"안녕하세요"`
- `상자<Integer>` : 라벨 `"용돈"`, 내용물 `50000`
- `상자<?>` 타입 변수에 용돈 상자를 담고, 그 변수로 라벨과 내용물을 출력

<details><summary>정답 보기</summary>

```java
// 4-1
class 상품 {
    String 이름;
    int 가격;
    int 재고;
}

상품 p1 = new 상품();
p1.이름 = "키보드";
p1.가격 = 30000;
p1.재고 = 5;

상품 p2 = new 상품();
p2.이름 = "마우스";
p2.가격 = 15000;
p2.재고 = 10;

System.out.println(p1.이름 + " " + p1.가격 + "원 (재고 " + p1.재고 + "개)");
System.out.println(p2.이름 + " " + p2.가격 + "원 (재고 " + p2.재고 + "개)");

// 4-2
class 상자<T> {
    String 라벨;
    T 내용물;
}

상자<String> box1 = new 상자<>();
box1.라벨 = "편지";
box1.내용물 = "안녕하세요";

상자<Integer> box2 = new 상자<>();
box2.라벨 = "용돈";
box2.내용물 = 50000;

상자<?> anyBox = box2;
System.out.println(anyBox.라벨 + ": " + anyBox.내용물);
```
</details>
